# freecell

Minimal FreeCell web app generated with AI.

- Play: deploy as static files (for example via GitHub Pages)
- Rules reference: https://en.wikipedia.org/wiki/FreeCell

## GitHub Pages deployment

This repository includes a GitHub Actions workflow that deploys the site to GitHub Pages.

1. In GitHub, open **Settings → Pages**.
2. Set **Source** to **GitHub Actions**.
3. Push to `main` (or run the workflow manually from the Actions tab).

After the workflow finishes, the app is published on the repository's GitHub Pages URL.
